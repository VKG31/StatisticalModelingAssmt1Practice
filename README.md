## Answering Basic Questions about the BES 
### What is the point:
This is a practice assingment both for my R class and for github. 
### About:
The BES (British Election Survey) is held in the lead up to every election in 20+ waves and includes opinion questions about voting habits, the economy, politicions and a host of other issues. I was tasked with utilizing R to determine some basic statistics about the 2019 survey. In the future readme's will be higher effort but for this private practice it feels redundant to explain everything.
